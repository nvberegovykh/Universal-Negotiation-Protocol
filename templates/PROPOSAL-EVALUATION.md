# Proposal evaluation

Status: TEMPLATE — this document is not an evaluation until completed and signed.

| Field | Required entry |
|---|---|
| Proposal | Identifier, version, full text/annex references, digest |
| Mandate | Agency and guideline version/digest |
| Reviewer accountability | Names, competence, affiliations, conflicts, verified signatures |
| SI/AI assistance | Actual system/version, capabilities used, validation and limitations; or unavailable |
| Scope | Questions evaluated and explicit exclusions |
| Evidence snapshot | Identifier and retrieval cutoff |
| Source coverage | Relevant local, regional, and global sources; gaps and contradictions |
| Freshness | Observation/publication/retrieval times, expiration by variable |
| Claim status | Observation, inference, assumption, forecast, value judgment |
| Formal checks | Units, calculations, inference, contradictions, reproducibility |
| Context checks | Applicable law, cultural interpretation, human and ecological effects |
| Implementation | Resources, incentives, dependencies, milestones, verification |
| Alternatives | Comparators and reasons for preferring or rejecting them |
| Uncertainty | Sensitivity, failure modes, confidence meaning and calibration basis |
| Disposition | Supported / conditional / unsupported / insufficient data / outside mandate |
| Conditions | Exact pre-adoption conditions and evidence of satisfaction |
| Dissent | Competing professional assessments and unresolved challenges |
| Validity | Issue time, expiration, and material invalidation triggers |
| Traceability | Reproducible methods and protected audit access |

If data or professional competence are unavailable, say so. Do not substitute a generated citation, assumed credential, or unsupported confidence score. Every material proposal revision needs a version-bound evaluation or a reviewed equivalence record.
